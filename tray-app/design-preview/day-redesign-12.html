Контекстное меню — одна механика для всех редких операций: right-click по строке → ✎ Edit · ★ Add to favorites · ✕ Delete (у записи, уже имеющей шаблон, пункт ★ скрыт); double-click = edit. Все время-инпуты (edit, review, jira-форма) крутятся колёсиком ±15m; ↩ на fresh-строке убран — ошибочный лог удаляется через меню. Edit — морф строки в форму ← [тикет] [activity] [время] [desc] [Save], тикет — лейбл. Delete — instant: Σ откатываются сразу, строка остаётся зачёркнутой с горящим ↩ undo ~3с, потом схлопывается; undo возвращает строку и Σ. Фавориты: ✎ edit в облаке — отметить чипы → Remove N (реюз batch-моторики); right-click по чипу → Remove from favorites; по Jira-результату → Save as favorite. Карандаш-колонка и arm-механики убраны.
