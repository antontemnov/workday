Ручной таймер — макет v12 · таймер среди иконок вкладок: циферблат вместо надписи

Продолжение v11: таймер ушёл из правого угла к иконкам вкладок — подальше от − ✕. Вместо надписи + Timer — циферблат в штрихе иконок вкладок: в покое тусклый, на ходу лаймовый, сектор = минуты текущего часа, на паузе красные полоски вместо стрелки, несколько таймеров — второй циферблат выглядывает сзади. Клик по циферблату в любом состоянии — меню; в покое в нём Start timer и Start on ticket…. Варианты группировки переключаются в панели: T1 своя группа за разделителем, T2 то же + время (секунды до часа), T3 четвёртой иконкой среди вкладок. Всё остальное — как в v11.

import { Injectable } from '@angular/core';
import { PaymentGateway } from './payment.gateway';
@Injectable({ providedIn: 'root' })
export class CheckoutService {
private readonly retryLimit: number = 3;
public constructor(private readonly gateway: PaymentGateway) {}
public async submit(order: Order): Promise<Receipt> {
const session = await this.gateway.open(order.id);
for (let attempt = 1; attempt <= this.retryLimit; attempt++) {
const result = await session.charge(order.total);
if (result.ok) return result.receipt;
// 500 on 3DS callback — reproduce before the ticket exists
}
throw new Error('charge failed');
}
}

Stop → черновик в ленте (пунктир + миллиметровка, лайм), возобновить нельзя; Log… появляется, когда известен тикет. Stop & new — то же + новый с нуля. New timer — текущий встаёт на паузу.

Виджет — отдельное окно поверх всех (как тост): непрозрачное, не берёт фокус → печатать в нём нельзя, описание правится в меню приложения. Unpin (булавка) — виджет пропадает, таймер остаётся в заголовке.
