Ручной таймер — макет v19 · таймер = источник времени, схема v18

Кликабельно. + Log — одно облако на всё: внизу ▶ Start timer (подпись идёт за строкой поиска — набрал текст, он станет описанием) и Create in Jira. Таймер без тикета — капсула рядом с + Log (K) или лейбл в заголовке окна (L): клик → маленькое меню (⏸/▶ · время · описание · ✕), строка → то же облако в режиме выбора тикета. Выбрал тикет — таймер уходит в карточку и сразу идёт в total: голое время — бирка timer added, с описанием — своя строка с ⏱. Stop нет: пауза отключает таймер, продолжить — ▶ Start timer в меню записи (клик по слову типа) у любой записи, кроме сессий. У идущей записи вместо ⏱ — кнопка ⏸, время с секундами. В форме облака — переключатель timer: Log пишет вписанные минуты и дальше считает.

Попробуй: + Log → набери «разбор 500-х» → ▶ Start timer «…». Потом клик по капсуле → строка → выбери тикет. Или + Log → тикет из jira → включи timer → Log.

Один источник за раз: старт любого таймера ставит на паузу идущий и живые сессии (yield). git-правка — сессия выигрывает, таймер встаёт с красным ⏸; вернуть — кликом.

Total = tracked + записи, включая время, которое прямо сейчас питает таймер. Таймер без тикета в total не входит, пока не выбран тикет.

Нет в макете: виджет поверх окон и иконка трея (без изменений с v13), Parallel-режим, правка описания таймера без тикета.
