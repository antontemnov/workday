Ручной таймер — кликабельный макет v34

Тот же макет, что v33, с тремя правками (часть 52). Сессия под таймером не заморожена: она вытеснена, а её стамина тает по часам — остановил таймер, пока стамина есть, и сессия снова считает; стамина вышла — остаётся Waiting, три часа тишины — закрывается сама. Одиночная правка счёт у таймера не отбирает — только правки подряд; таймер возвращается сам, когда сессия полностью угасла. Remove timer вместо Remove timer time: снимает таймер с записи целиком.

Сессия под таймером. Сцена «таймер поверх живой сессии» → ⏸: стамина ещё есть, сессия снова считает. Та же сцена → «15 минут» тишины → ⏸: никто не считает, сессия осталась Waiting. «5 часов» — сессия закрылась сама, как закрывается и без таймера.

Перехват. Пока идёт таймер: «одна правка» — счёт остаётся у таймера, сессия получает заряд, но не лидерство. «Плотные правки» — считает сессия, таймер ждёт (оранжевый вполсилы). «15 минут» тишины — стамина сессии вышла, таймер идёт дальше сам.

Remove timer. Сцена «запись: 2h руками + таймер» → клик по слову Code Review → Remove timer −47m: уходит время таймера, ▶ у времени и строка в острове, запись остаётся обычной. У записи, целиком выросшей из таймера, такого пункта нет — там Delete.

Строка под панелью — показания самого макета, в приложении её нет: состояние сессии, остаток стамины и «внимание», по которому демон выбирает лидера.

Остальное — как в v33: клик по «Timer» → описание → Enter; task? → тикет → Log; запись тикает, ⏸ рядом со временем; правка: время поменял — счёт идёт от нового значения; булавка включает виджет.

В макете нет: смены дня (в 04:00 всё встаёт; время таймеров без тикета сохраняется как несвязанное — дизайн позже), перетаскивания виджета, иконки трея. Модель стамины упрощена: без ускоренного остывания после плотной работы.
