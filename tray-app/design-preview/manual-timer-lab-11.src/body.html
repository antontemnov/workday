Ручной таймер — макет v11 · таймер вне ленты: заголовок окна, виджет поверх окон, трей

Кликабельный макет на снимке живого трея (мок-режим). Таймер — инструмент, а не данные: пока идёт, живёт в заголовке окна (общем для Day / Sheets / Settings), в виджете поверх окон и в трее; в ленту попадает только на Stop — черновиком под Log. Начни с + Timer в заголовке окна справа. Клик по таймеру — меню; task? — облако тикетов с Create in Jira; время в меню — правка (колесо ±15); виджет таскается, тянется за угол, ⏵/⏸ — кнопка слева, клик по телу — открыть приложение с меню. Кнопка «git-правка» имитирует оживание сессии.

import { Injectable } from '@angular/core';
import { PaymentGateway } from './payment.gateway';
@Injectable({ providedIn: 'root' })
export class CheckoutService {
private readonly retryLimit: number = 3;
public constructor(private readonly gateway: PaymentGateway) {}
public async submit(order: Order): Promise<Receipt> {
const session = await this.gateway.open(order.id);
for (let attempt = 1; attempt <= this.retryLimit; attempt++) {
const result = await session.charge(order.total);
if (result.ok) return result.receipt;
// 500 on 3DS callback — reproduce before the ticket exists
}
throw new Error('charge failed');
}
}

Yield (дефолт): старт/возврат таймера ставит живые сессии на паузу; свежая git-правка — сессия выигрывает, таймер встаёт; обратно — только кликом. Parallel: никто никого не паузит.

Stop → черновик в ленте (пунктир + миллиметровка, лайм), возобновить нельзя; Log… появляется, когда известен тикет. Stop & new — то же + новый с нуля. New timer — текущий встаёт на паузу.

Виджет — отдельное окно поверх всех (как тост): непрозрачное, не берёт фокус → печатать в нём нельзя, описание правится в меню приложения. Unpin (булавка) — виджет пропадает, таймер остаётся в заголовке.

Облако одно на Log и на таймер; в режиме таймера без минут и multi. Create in Jira открывает форму создания в браузере; созданный тикет — первым чипом.
