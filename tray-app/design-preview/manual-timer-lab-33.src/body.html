Ручной таймер — кликабельный макет v33

Собрано из принятого (части 46–50). В шапке приложения один элемент: в покое значок + Timer, клик — таймер идёт, курсор в описании. Чип — вход в остров: в нём живут все таймеры дня. Таймер без тикета — в два этажа: ▶ / ⏸ · task? · описание · время, ниже Delete. task? открывает облако выбора тикета под строкой и состояние таймера не меняет. После Log строка остаётся — с ключом тикета и в один этаж, а в карточке появляется запись: оранжевое время с секундами и ⏸ рядом. В каждый момент копит кто-то один: git-правка перехватывает счёт, сессия затихла — таймер возвращается сам. Булавка внизу острова включает виджет поверх окон.

Попробуй: клик по «Timer» в шапке → набери описание → Enter. Потом task? → выбери тикет → Log: строка осталась в острове с ключом, в карточке тикает запись. Нажми «git-правка», затем «сессия затихла» — таймер вернётся сам.

Один источник за раз. Запуск таймера ставит идущий таймер на паузу, а живую сессию отправляет в Waiting. git-правка: сессия считает, таймер ждёт (тот же оранжевый вполсилы). Сессия затихла — таймер идёт дальше. Пауза руками (⏸) — это уже стоп до ▶.

task? таймер не останавливает: шёл — идёт дальше в записи, стоял — стоит. «Закончил — записываю» = сначала ⏸, потом task?.

Запись. Клик по слову типа — меню: Start timer (если у строки нет своего ▶), Edit, Remove timer time, Delete. Правка: время поменял — счёт идёт от нового значения; не менял — таймер не тронут.

Total = tracked + записи, включая время, которое прямо сейчас кормит таймер. Таймер без тикета в total не входит.

Смена дня (в макете нет): в 04:00 всё встаёт на паузу, строки с тикетом из острова уходят, таймеры без тикета удаляются.

Упрощено: форма правки записи — приблизительная (в приложении своя); виджет не таскается; иконки трея нет.
