Ручной таймер — макет v14 · полоски таймеров примагничены к шапке дня

Меню v13 ушло целиком. Таймеры живут вторым этажом шапки Day (дата · + Log · total): узкие однострочные полоски на её стекле, шапка sticky — полоски видны при любой прокрутке ленты. Полоска — элемент управления, а не запись: она утоплена в стекло (лоток), карточки ленты наоборот приподняты. Минуты полоски стоят по правой кромке total. Строка: ▶/⏸ · тикет или task? · описание ··· минуты; при наведении слева от минут проявляются Log… 📌 ✕ (фона у строки нет). Stop и черновиков больше нет: Log… раскрывает полоску в форму Log прямо на месте (форма строки лога: ← · вид работы · описание · Log, минуты в своём слоте), Log — полоска уходит, запись опускается в ленту, total вырастает. ✕ — выбросить. Создание — клик по циферблату в заголовке окна (с любой вкладки): Day + пустая заготовка с курсором в описании; ушёл, ничего не вписав — она исчезла. Тикет — клик по task? → облако открывается под шапкой вместе с полосками. Циферблат, виджет, трей, Yield / Parallel — как в v13.

private readonly retryLimit: number = 3;
public constructor(private readonly gateway: PaymentGateway) {}
public async submit(order: Order): Promise<Receipt> {
const session = await this.gateway.open(order.id);
for (let attempt = 1; attempt <= this.retryLimit; attempt++) {
const result = await session.charge(order.total);
if (result.ok) return result.receipt;
// 500 on 3DS callback — reproduce before the ticket exists

}

Почему шапка дня: путь шапка → полоски → лента короткий и видимый; Log опускает полоску на шаг вниз, без телепорта из всплывающего меню. Шапка — уже зона учёта (+ Log, total), незалогированное всегда на виду.

Полоска ≠ карточка: утоплена (тёмный жёлоб с внутренней тенью), без плиты и рамки; лаймовый — только у идущего (глиф и минуты). Поверхность переключается: лоток · лунки · на стекле.

Log… = конец таймера. Минуты подставлены округлённые, правятся колесом ±15 или руками; без тикета Log погашен. Пока форма открыта, таймер идёт дальше — в запись уходит то, что в поле.

Yield (дефолт): старт/возврат таймера ставит живые сессии на паузу; свежая git-правка — сессия выигрывает, таймер встаёт; обратно — только кликом. Parallel: никто никого не паузит.

Виджет — одно окно поверх всех, стопка запиненных; клик по нему — приложение впереди на вкладке Day.
