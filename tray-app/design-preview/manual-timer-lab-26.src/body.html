Ручной таймер — макет v26 · таймер без тикета = строка внизу шапки дня

Кликабельно; логика v19, шапка по v22-слева. Пока таймера без тикета нет — шапка 1 в 1 как сегодня. Есть — шапка растёт на одну строку: циферблат · время · описание · ▾; + Log и total не двигаются. Циферблат несёт состояние: стрелка и лаймовый сектор (минуты часа) — идёт, красные полоски — пауза; таймеров больше одного — второе кольцо за циферблатом, виден один (идущий или последний). Клик по строке — маленькое меню (⏸/▶ · время · описание · ✕), строка меню — облако выбора тикета. Рождается таймер в облаке + Log: внизу ▶ Start timer, подпись идёт за строкой поиска — текст станет описанием. Дата не кликабельна. Выбрал тикет — время уходит в запись карточки и сразу в total: голое — отдельная бирка timer added (пауза — внутри неё, на месте ⊕), с описанием — своя строка с ⏱. ▶ у любой записи, кроме сессий, — пункт Start timer в меню записи (клик по слову типа); у manual added он кладёт время в соседнюю timer added. В форме облака — переключатель timer.

Попробуй: пусто → + Log → набери «разбор 500-х» → ▶ Start timer «…» — шапка вырастет на строку. Клик по строке → строка меню → выбери тикет — строка уйдёт, время упадёт в карточку и в total. Или + Log → тикет из jira → включи timer → Log.

Один источник за раз: старт любого таймера ставит на паузу идущий и живые сессии (yield). git-правка — сессия выигрывает, таймер встаёт с красными полосками; вернуть — в меню.

Total = tracked + записи, включая время, которое прямо сейчас питает таймер. Таймер без тикета в total не входит, пока не выбран тикет.

Нет в макете: таймер на вкладках Timesheets / Settings (строка живёт в шапке Day), виджет поверх окон и иконка трея, Parallel-режим, правка описания таймера без тикета.
