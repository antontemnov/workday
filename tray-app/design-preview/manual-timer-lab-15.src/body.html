Таймер без тикета — мини-макеты блока «шапка дня + облако» · v15

Принято (части 22–25): таймер — источник времени для поля минут; Stop нет — пауза = отключение; ▶ там, где время записи можно править (не у сессий); без тикета таймер — капсула с тикающим временем рядом с + Log, вне total; с тикетом — питает запись в карточке, сразу в total; голое время — timer added, участие таймера — глиф ⏱. Здесь только один вопрос: откуда стартует таймер без тикета. Колонки — варианты входа, строки — состояния. Макет статичный, без логики.
